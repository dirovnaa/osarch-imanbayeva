# PCPartPicker lists (23.11.2026)

PCPartPicker does not price in tenge and does not list every Kazakhstan model, so these lists are used **only for compatibility and estimated wattage**. Where the exact shop.kz model was not in PCPartPicker, the nearest equivalent was used (same socket / memory type / form factor):

| In budget.csv (shop.kz) | In PCPartPicker |
|---|---|
| MSI PRO A620AM-B Evo | MSI PRO A620M-B (same board, earlier revision) |
| Samsung 990 1 TB NVMe | Samsung 990 EVO Plus 1 TB NVMe |
| Ocypus Gamma C60 (Micro-ATX/ATX) | Deepcool MATREXX 30 (Micro-ATX) |
| Netac / AMD Radeon R5 DDR5-5600 | Crucial / Kingston FURY DDR5-5600 desktop DIMMs, same capacity |
| ID-Cooling SE-904-XT (AM5) | ID-Cooling SE-214-XT (AM5) — designer list only |

| Build | Link | Estimated wattage | Result |
|---|---|---|---|
| 1. Accountant | https://pcpartpicker.com/list/MBwZqd | 144 W | compatible; note: with the Ryzen 5 8500G (Phoenix 2) the PCIe x16 slot runs at x4 |
| 2. Sales manager | https://pcpartpicker.com/list/YgR6K7 | 160 W | compatible; same x4 note |
| 3. Web developer | https://pcpartpicker.com/list/zk4hYX | 160 W | compatible, no notes |
| 4. Designer | https://pcpartpicker.com/list/7cdcyF | 170 W | compatible, no notes |

The highest estimate, 170 W, is under a third of the 550 W power supply.

PCPartPicker counts the boxed CPU's included cooler for the 8500G and 7700. The shop.kz processors are **OEM** (no cooler), so the real builds have a separate ID-Cooling SE-904-XT in every machine (budget.csv). The first designer list, with a Ryzen 5 9600X, showed an orange warning — "does not include a stock CPU cooler" and "BIOS 7E28vB2 needed" ([not-used/pcpartpicker-9600x-no-cooler-warning.png](not-used/pcpartpicker-9600x-no-cooler-warning.png)); that is what led to the change.
